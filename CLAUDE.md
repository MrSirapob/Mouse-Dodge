# CLAUDE.md

This project's AI-onboarding doc lives in **[AGENTS.md](./AGENTS.md)**, not
here — kept in one place so it can't drift out of sync between AI tools.
`CLAUDE.md` exists only because Claude Code looks for this filename
specifically. Read `AGENTS.md` first, and check
**[HANDOFF_LOG.md](./HANDOFF_LOG.md)** for what the last session (possibly
a different AI tool) did — and add your own entry there when you finish.
